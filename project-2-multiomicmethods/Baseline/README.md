# Baseline Notebook Environment Setup

To run the notebook **Baseline.ipynb**, follow these steps to set up the required environment.

## Prerequisites

- Python 3.8 or higher
- pip (Python package installer)

## Environment Setup

1. Create a conda environment:
   ```bash
   conda create -n baseline python=3.10 -y
   ```

2. Activate the environment:
   ```bash
   conda activate baseline
   ```

3. Install the required packages:
   ```bash
   pip install -r Baseline/requirements_baseline.txt
   ```

## Notes

- Ensure you have the necessary data files in the correct directory structure.
